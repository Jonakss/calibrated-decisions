Calibrated Decisions

A visual playground for the Pollinations typed-decision API (POST /alpha/decisions, powered by Jev). Build a decision request, send it, and read the calibrated probabilities — no token-by-token output, just calibrated answers.

Powered by Pollinations — decision API: POST https://gen.pollinations.ai/alpha/decisions · Jev returns calibrated probabilities for choice, score and noul questions, with routing metadata. Your key stays client-side; requests go straight to the gateway. Learn the schema gotchas in the community tips.
